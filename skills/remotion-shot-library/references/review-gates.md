# 保真审核

Gate 1 审核参考机制与感知保真，必须核对真实 MP4，不能只看 PNG、代码或 JSON。覆盖起始、主要过程、稳定态、危险转场与结束，检查同帧并正常速度完整播放。技术解码通过不代表视觉通过。

对象、动作、支点、遮挡、层级、时序、字体、纹理、光影、焦点场与音画关系存在可辨缺陷时修正。缺少插件允许有证据的机制等效；已知差异需具体披露，不能以宽泛近似掩盖根本错误。

只有用户明确批准当前成片后，记录对应 SHA-256；成片改变则旧批准不覆盖新文件。参考素材的内部批准不等于对外发布许可。公开发行止于 Gate 1，查看器可以展示用户既有的 Gate 2 记录，但不提供认证、调用或外部发布。
