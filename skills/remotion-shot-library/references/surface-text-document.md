# 文字、材质、背景与文献效果识别

有文字、文献、材质背景或焦点滤镜时读取对应章节。以真实源片帧和正常速度证据判断，不从效果名字直接猜实现。

## 文字属性与复合显影

标题、表头、正文、数字、注释分别测量：内容、字体候选及置信度、字号、字重、字宽、字距、行距、锚点、覆盖面积、行数、对齐；填充的纯色/渐变/纹理/媒体；描边、内外阴影、实体投影、高光、辉光、倒角、色散、镂空、混合模式；上下局部透明度、字形内颗粒、掉墨、破损和扫描质感。某角色倾斜不代表其他文字也倾斜。

出现过程多标签记录显影单位、二维空间分布、清晰度、几何运动、颜色/透明度、纹理、归属和先后交接。逐帧检查块尺寸、数量、空间分布、聚合方向、字形形成顺序和整字接管时机。色块建立与失焦到凝实可同时存在；横向条带、整行淡入、打字与二维块聚合不是等价机制。块数量来自当前参考，不固定照搬某例的 10×6。

字形附着的火焰、掉墨或纹理通过蒙版/填充/混合层与文字绑定，检查离开字形边界后的行为。不能只在纸面加噪点、整字降透明度或叠无关贴图来替代字形内破损。选择版本锁定字体并实际加载后测量；不得以字符数量、负字距或固定坐标掩盖堆叠。小屏可读性以成片实际尺寸/占屏和正常速度检查，不用缩略图估计几何。

带色块的放大结论需分开记录完整终态边界和显影期可见边界。文字已可读不代表色块已经展开完；至少追踪到宽度稳定，再绑定引线端点。调整字体、字框或色块宽度后，检查引线与目标边角在显影、稳定和父组移动期的连接，不能把中间显影宽度固化成终态并留下悬空线端。

### 大字的实际笔画厚度

背景字、大占屏标题和巨型数字必须在相同占屏尺寸下比较实际笔画，`fontWeight=900` 本身不证明足够粗。可见的字重差距不能只列作“字体未知”的普通差异后收口。原片本身细的正文、英文注释或小字不机械加粗。

大字号也可能采用疏朗点阵或明确的细笔画设计。若原尺寸源片证明点数、点距和细笔画属于该字形机制，保留其疏密，不因占屏大而填实格子；“补足视觉重量”针对候选比原片偏弱的差距。整字、最窄字内孔和点阵留白都需保留同尺寸证据。

先在源片与实际 MP4 的稳定字形、最终推进或最大占屏帧上排除背景与阴影，分别观察竖笔、横笔、撇捺、字面覆盖密度和字内空隙。位置与外框接近但笔画明显弱，仍需修正。优先选择更接近的重体字形或可用字体的重量轴；再用受控描边补足，描边随字形处于同一局部坐标与父层。不能靠加大字号、缩字距或把字内孔封死制造粗重感。

先取最窄字内孔的字符验证粗度上限，再检查整行、运动期和最大占屏。减描边恢复字内孔不自动证明已经达到原片粗度；同时保留厚度与空隙两项证据。字体身份无法确认允许采用等效字体，但大字仍须满足当前源片的视觉重量。

### 连续渲染中的字形与照片完整性

单张 still 正常不证明实际 MP4 正常。复杂变换、滤镜、透视文字或照片蒙版出现缺字、缺片时，从连续成片提取相同帧，定位字形覆盖、照片存在性、父级坐标与显影进度。保留最小失败证据后，再选择 DOM/CSS、SVG 或 Canvas 的等效实现。不能把某个组合失败推广成整个技术栈不可用。

文字使用真实加载字体与基线，清晰层和模糊层同位，保持父组运动、渐变、光效及逐字时序。Canvas 只在较简单实现不足且有实际失败证据时采用，文本保持可编辑；不能改用源片文字位图。照片合成必须等待媒体加载完成，保持坐标、碎边、透明度、显影量与焦点场。

修复后的存在性或局部像素检查不证明整体质感保真，仍须同帧和正常速度完整观看。局部阈值只适用于相应素材，不自动授予 Gate 1。

## 背景基底与处理栈

背景只有构造型与媒体型两类基底；动态是属性，不新造第三类。媒体图叠纹理仍是媒体基底。独立记录基底来源、裁切、焦点、调色、纹理尺度、颗粒、模糊、暗角、混合模式、光影与叠加顺序，再记录各参数时序。

分离素材内部播放、背景层变换、摄影机运动和环境持续微动。记录循环周期、接缝、速度、方向、幅度和前中后状态；源片动态却做成静态默认失败，例外须有连续证据。检查背景既可感知又不抢主体阅读焦点。

多排/多层媒体须分别记录方向与不变量，不能把相反方向流动和静止中排合成一次全局位移。相机回拉与对象缩小分开判断；具体倍率从当前来源测量，不从旧样本继承。

织物看经纬交织、斜纹方向、纤维随机性、密度和暗部层次；石材看颗粒/裂纹尺度及分布，不用规则网格代表所有材质。照片包装保留白边、视口、纸面和边缘处理。空间感同时检查环境、后景、中景、前景和全画面处理的相对尺度、旋转、遮挡、清晰度和投影。

### 背景质感的单独验收

背景占据较大画面、承担材质世界或空间层次时，不能只实现对象后补一层弱噪点。明显缺少纹理或明暗层次的候选须返修，不能用“背景近似”收口。

抽帧明暗接近仍须核对实际播放器。分别核验源片、抽帧和播放器的色域、传递函数、矩阵、范围及 ICC；根据当前证据选择中间帧格式与正确的输出色彩配置。不能机械将 HDR 或其他来源全部标成 BT.709，不能只改元数据标签掩盖错误像素，也不能提亮背景补偿播放链差异。修改既有候选时保留旧文件、比较编码前后画面、验证音轨与帧数，复查正常播放并绑定新哈希。

在前景未遮挡的同帧区域及正常速度全画面，逐项对比基底明暗范围、纹理尺寸/方向/疏密、颗粒对比、裂纹或纤维结构、网格粗细、焦点与羽化、暗角、局部光向和持续动态。至少保留一处原分辨率局部对照与一处完整画面；纹理在放大局部可见、缩回原占屏却消失，说明其视觉强度仍不足。像素或频率统计仅辅助，先排除文字、人物、边框和压缩噪点，不能用高频总量代替材质判断。

使用局部背景补洞时保留未遮挡区的真实纹理尺度；补洞区不能出现软糊矩形、重复平铺接缝、拉伸条带或突然消失的结构纹理。需要重建时，基底、材质纹理、光影与全画面处理分层参数化，再结合源片校准。静态对照成立后仍检查动态、相机绑定与过渡，避免背景质感只在一帧成立。当前序号保存修正前后同帧和成片哈希；这些是内部保真检查，不授予用户 Gate。

从源帧提取胶带、纸面或透明装饰时，先排除屏幕固定水印和字幕，再映射到对象坐标。不得把覆盖在素材上的水印残字变成随卡片运动的新内容；优先取该对象未被遮挡的帧，始终被遮挡的局部使用有证据的材质等效并披露。透明边缘和补片既看原尺寸，也检查全段退远后的画面，防止出现白色矩形、残留笔画或硬切下缘。

方向性线光记录光源侧、方向、扇区/宽度、衰减、作用层和可见强度。右上向左下的束光不能用圆形泛光替代。人物轮廓光沿主体边界工作，圆形光晕只能是有依据的补充；光效、蒙版和相机目标一起适配新主体。

局部反相、换色或滤镜窗口须区分场景内容、材质纹理与全画面光场的处理顺序。窗口经过暗角或边缘光区时，检查源片的明暗是否一起反转；不能因背景贴图已含暗角就自动将它纳入反相。若源片暗角在局部效果之后仍成立，应拆出光场并按证据顺序合成，保持窗口内外的纹理坐标和人物遮挡。检查窗口初现、最大范围与画面边缘交叠，避免稳定中间帧成立、尾段却出现无来源的白色泛光。

## 同位焦点场

先确定滤镜属于全画面、背景、报告容器还是单对象，记录清晰区中心、半径、羽化、模糊强度和时间。多层合成时清晰层与模糊层必须同坐标、同尺寸、同缩放、同父级运动；只改变模糊和蒙版，不能额外平移或外扩缩放制造第二份画面。

在中心、羽化带和边缘检查同一字形、表格线、纸边的配准。第二轮廓、双字边或错位表格线判重影；主要阅读区也不能糊到不可读。扩展滤镜采样边界不等于改变原画面几何。

## 文献证据与转译

文献分原始底图、文字区、非文字版面、当前引用范围、转译层和强调层。记录标题、作者、日期、页码/来源 URL；OCR 文字框用于辅助，不覆盖原图事实。原文与译文/转述逐项对应，标明覆盖、并列、替换或重排，不凭模糊截图编造文字。

记录高亮背景的颜色、范围、圆角、透明度、混合模式；强调单位是词、行、段还是随口播推进。非文字退后层另记降透明度、模糊、去饱和或压暗的范围与强度；不能连引用文字一起整体变淡。明确保留哪些版式维持证据可信感，观众应读原文、识别来源、理解结论还是感知证据存在，并给足阅读时间。

纸面石材/纤维、字形掉墨与报告焦点场是三个不同作用域。表头下半透明属于字形纵向处理，不是整纸暗角或未完成显影；标题是否正体单独核对。标题、表头和各行可随纸张上移依次建立，组内从左到右揭示；父组位移和子层遮罩并发，不能整页同步淡入。圈选保持独立书写时序，不参与文字显影，随报告同一父级运动。

解释选择哪段文献、强调哪些词、弱化哪些区域，以及它如何支持当前观点。演示数据标为虚构，不把样式验证伪装成事实材料。

## 代表证据与检查

首次复刻覆盖起始占屏、文字首次出现、表头/逐行建立、圈选起笔、推进开始/结束和圈选闭合。分别检查文字高度、原比例、材质作用域、同位模糊、路径完整性和真实阅读时间；既看远景，也看最终近景。认证调用只复查本次换内容可能影响的区域，不重新研究原片。

精确参数保留在各条测量真值，不写成通用强制值。

只读取当前问题的最终有效结论与证据，旧参数已标废止的不重新采用；不要求新镜头复制旧文案或数值。
