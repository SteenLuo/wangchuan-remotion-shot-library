# 来源合同

用户直接提供视频是正式来源，无需飞书。先校验可解码性，复制到项目内 sources/direct/{sequenceId}/，以 SHA-256 校验副本一致。记录来源类型、原文件名、项目相对路径、尺寸、帧率、时长、帧数与导入时间。

sequenceId 使用 seq-NNNN 格式；未指定时从已有来源和镜头目录分配下一个未占用编号。相同哈希复用原编号，不同哈希不覆盖旧编号；同名不同文件需明确修订决定。只读用户原文件。

使用分项 Skill 中的 import-source.mjs。外部来源映射可为空。素材副本、来源记录和测量证据保留在个人本地，禁止进入公开仓库。不可读、不可解码、副本哈希不符或编号冲突时停止，报告具体缺口。
