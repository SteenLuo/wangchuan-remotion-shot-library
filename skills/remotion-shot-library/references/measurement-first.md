# 先测量后实现

这是一条低自由度流程。不得先凭语义描述搭出近似动画，再靠审阅逐轮校正。

## 实现前的源片几何账本

对起始、每个动作边界、转折极值、稳定状态、交接前后和结束帧逐项记录：

- 元素稳定 ID 与语义角色；
- 完整边界 `x/y/w/h` 和归一化边界；
- 可见裁切边界及被哪一层或画布裁切；
- 旋转角、缩放、锚点和层级；
- 包装外框与内部素材视口，二者的 inset 和运动绑定；
- 当前帧应出现、应退场、正在进入和承接自上一镜头的成员；
- 背景文字的不可见布局范围、参考字数、行数和溢出策略。
- 背景类型、纹理尺度、动态、光源方向、光束范围、景深与中间清晰/边缘模糊的作用域；
- 文献的纸张完整边界、表头/正文、逐区揭示、纹理与圈选目标；
- 连接线、图钉、锚点、远距离投影和目标对象的几何关系。

完整尺寸不能从裁切后的可见碎片质心反推。应结合已知宽高、边缘、旋转和连续帧恢复完整变换。

## 动作账本

分别测量每个通道：`translateX`、`translateY`、`scale`、`rotate`、`opacity`、遮罩/裁切和相机。线条绘制另记路径进度。对快速位移、摆动、翻页、像素聚合和手绘路径每 1–2 帧取样，先得到方向序列、极值、动作次数、节拍、相位连续性和不变量，再拟合最简单的连续函数。

## 编码门禁

只有几何账本、动作账本和稳定状态成员表全部完成，才允许写 TSX。组件默认值必须来自账本；描述文本只能帮助解释语义，不能替代坐标、尺寸和时间测量。

## 首轮质检

首轮渲染后立即生成源片/复刻同帧板，逐项比较：

1. 同一帧的成员是否一致；
2. 完整边界、可见裁切和层级是否一致；
3. 包装与视口是否同步且没有误加描边；
4. 动作方向、次数、极值、节拍和交接关系是否一致；
5. 背景文字换字后是否仍受不可见范围约束。
6. 图钉是否保持固定，照片是否从正确遮挡层下出现，依附线条/影子/相机是否仍指向目标。
7. 模糊、阴影、远距离投影和文字效果的作用层是否与源片一致。

再按正常速度完整观看。静帧通过但正常速度突兀，仍判失败。

## 失败反馈闭环

先将失败归为：源片区间、几何提取、裁切推断、成员/语义分组、时间映射、动作拟合、生成器、渲染器或素材特例。

- 若同类问题可能再次出现，先更新共享 schema、脚本、生成器、验证器或本 Skill，再修当前镜头。
- 若仅为当前素材特例，记录证据后修当前组件。
- 只重建失败序号；组合镜头只追加重建从该序号开始的依赖后缀。
- 局部重建审阅清单时合并既有条目，禁止清空无关序号的证据。
