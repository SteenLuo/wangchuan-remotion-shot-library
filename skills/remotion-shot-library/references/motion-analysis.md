# 视频运动解析规范

在创建或修改 `motion-timeline.json` 与 Remotion 动画前完整读取本文件。

## 核心原则

密集抽帧是测量证据，不是关键帧列表。先归纳动作语法，再以逐帧数据验证和拟合。不要把检测噪声逐项写入动画。

## 1. 建立运动组

按共同运动关系组织元素：包装、装饰和素材窗口若一起移动，应属于一个外层运动组；内部视频播放、素材相关标注和外层构图运动分别建模。记录旋转中心、完整元素宽高、裁切和遮挡关系。

部分入画时，不能用可见碎片的中心代替完整元素中心。根据完整几何、已知尺寸、边缘和旋转反推元素变换。

## 2. 分离动画通道

先按来源分六类：摄影机、对象、素材内部、效果参数、路径/遮罩、环境持续微动。再在每类中分以下数值属性，不把这些属性误称为六类来源。

分别分析并保存：

- `translateX`
- `translateY`
- `rotation`
- `scale`
- `opacity`
- mask / clip / reveal
- camera pan / zoom / focus target

annotation path progress 属于路径类，z-order change 作为事件另存；媒体播放和环境微动不能因为没有 transform 就被省略。

一个通道恒定时把它声明为不变量，例如纯垂直入场的 `translateX=0`。用自动测试验证，不用肉眼猜测。

## 3. 写动作语法

在记录大量数值前，先形成可读结构：

- 初始状态和最终状态；
- 动作方向序列；
- 极值、转折和停顿次数；
- 周期、半周期或阶段时长；
- 幅度是否衰减；
- 缓动、回弹、惯性或匀速特征；
- 与入场、落定、绘制、遮挡等事件的相位关系。
- 触发者、受影响对象、父子绑定、遮挡揭示、固定锚点和动作结束后的持续行为。

若语法无法解释观察到的运动，继续分析，不进入实现。

## 4. 密集采样与去噪

高速位移、摆动、回弹和手绘区间每 1–2 帧采样。采样用于寻找：

- 起止帧；
- 轴向轨迹；
- 极值和方向变化；
- 相邻阶段间隔；
- 振幅包络；
- 多通道同步关系。

将孤立反向、中心突跳和不合理变频视为候选测量误差。只有连续帧、几何关系和整体语法同时支持时，才保留为真实动作。

## 5. 拟合运动模型

最终时间线使用能解释源片的最简连续模型：语义关键帧、统一缓动、正弦/阻尼摆动或可复现弹簧参数。不要为了追逐检测小数而制造密集的不等间隔关键帧。

同一运动通道必须跨事件边界保持连续。元素落定只代表位移结束，不代表仍在运行的旋转需要重启、变频或改变相位。

动作必须满足空间因果：被图钉固定的照片围绕图钉转动，图钉本身不摆动；从主照片下方散出的子照片先处于遮挡层下再滑出；连接线从真实结构锚点出发，装饰图钉不自动升级为锚点。不能把持续动作机械拆成“入场—静止—再运动”三段。

每个模型保存：

- 方向模式；
- 语义关键帧；
- 周期或各阶段间隔；
- 缓动或物理参数；
- 通道不变量；
- `observed` / `inferred`；
- 置信度和证据帧。

## 6. 内部验收

给用户看预览前必须完成：

1. 源片与复刻在相同帧号的对照，覆盖开始、极值、转折、事件交界和结尾；
2. 正常速度播放，人工计算动作次数与方向；
3. 必要时慢速播放，检查频率、缓动和相位连续性；
4. 自动验证恒定轴、方向序列、关键帧间隔、总帧数和最终状态；
5. 检查旋转围绕正确中心，包装与素材窗口没有脱离；
6. 素材相关标注绑定真实目标；开放或闭合服从源片与语义，框选末态必须完整包围目标，不强制全部开放，也不默认通用圆。

如果自动验收发现动作数量、方向、节拍或轨迹和动作语法不一致，禁止输出用户预览。

每个原子镜头必须保存 `motion/motion-measurement.json`，至少包含：源视频相对路径与分段帧范围、运动组、因果动作序列、各组变换采样、事件及证据帧、蓝图帧、三处以上同帧对照。首次复刻渲染只接受结构完整的 `measured` 或 `qa-passed`；认证模板调用依赖已经冻结的运动真值，不重复生成本文件。

## 空间约束的详细执行

固定物、遮挡发散、连线/投射影或相机焦点命中时，完整读取 [spatial-motion-mechanisms.md](spatial-motion-mechanisms.md) 的对应章节。必须区分参照坐标系、物理固定与关系源节点；不能只按“照片摆动”一句话实现。
