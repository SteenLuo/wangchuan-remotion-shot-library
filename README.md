# WangChuan · 镜头库

**wangchuan-remotion-shot-library** — 参考镜头复刻技能与本地镜头查看器。

这个公开项目提供方法和工具。WangChuan 的私人镜头库、视频成果、素材、成品组件、测量参数和审核记录不包含在仓库中。

## 打开镜头库

安装 Node.js 24 或更新版本，进入项目目录运行：

```sh
npm run viewer
```

打开终端显示的本地地址，默认是 `http://127.0.0.1:8848`。查看器没有第三方前端依赖，不需要先安装 npm 包；首次启动显示空库。安装 FFmpeg 并将其加入 PATH 后，页面会为已登记视频生成缩略图。没有 FFmpeg 时仍可播放浏览器支持的视频。

查看器支持名称、编号、关键词搜索，类型与阶段筛选，编号或更新时间排序，多版本视频播放、拖动进度和全屏。视频哈希与批准记录一致时才显示“保真已通过”或“彩色已通过”。页面只读，不改变审核状态，不认证或调用模板。

## 使用复刻技能

在支持本地 Skill 的智能体中加载 [技能入口](skills/remotion-shot-library/SKILL.md)。明确提供参考视频和需要复刻的片段；智能体按来源导入、观察、测量、Remotion 实现、实际视频验证和用户审核顺序工作。需要可用的 Remotion 工程及 FFmpeg；本项目不捆绑私人 Remotion 组件，也不承诺一键自动复刻。

直接导入自己的参考视频：

```sh
npm run source:import -- --file "/path/to/reference.mp4"
```

导入工具生成不可变副本、稳定编号和 SHA-256，拒绝重复编号与不同来源冲突。参考视频只用于获授权的内部分析；复制机制不意味着获得原作者素材的发布许可。

## 登记自己的成片

先将视频放入本项目 `library/` 目录，再运行：

```sh
npm run viewer:register -- --id seq-0001 --title "我的第一个镜头" --file library/my-shot.mp4
```

登记命令仅加入“本地预览”，不会替您批准视频。网页点击刷新即可查看。数据合同和接入已有项目的方法见 [查看器文档](docs/viewer.md)。

## 公开边界

仓库只包含两个主能力：复刻、查看。模板认证、生产调用、外部发布和作者私人镜头库不在公开发行范围。

`library/`、`catalog/`、`sources/`、`out/`、`public/`、`remotion/`、本机配置和缩略图缓存都被 Git 忽略。页面只监听 `127.0.0.1`，不上传视频、不加载外部字体或统计服务。请勿将私人目录改为公开静态资源目录或部署至公开站点。

首次公开发行采用全新 Git 历史，不携带私人项目的历史提交。提交前运行：

```sh
npm test
npm run privacy:check
git diff --check
```

可在此仓库启用提交前检查：`git config core.hooksPath .githooks`。它只影响当前仓库，检查待提交文件是否属于公开清单，以及暂存内容是否与已检查文件一致。GitHub 也会执行自动检查。

公开可见不等于授予任意再许可；本仓库未附加开源许可证。Remotion、FFmpeg 和其他可选工具按各自许可使用。
