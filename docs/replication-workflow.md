# 公开发行复刻流程

本文件定义 WangChuan 公开发行的工作范围，与技能入口一起使用。

## 流程

用户选片 → 来源副本和哈希 → 最小语境 → 全片段对象观察 → 几何与动作测量 → 参考配置实现 → 实际 MP4 与同帧验证 → 正常速度完整观看 → 用户 Gate 1 批准。

来源无关，直接视频不依赖外部记录。`sequenceId` 是永久编号，来源哈希用于去重。观察事实、推断、个人评价分别记录。

## 保真要求

保留对象关系、动作顺序、遮挡出场、轨迹方向、支点、视觉焦点、持续运动及可感知质感。媒体保持比例；清晰层与模糊层共享几何和父运动；字体、笔画、材质、背景、灯光和蒙版分别检查。案例参数不能成为所有镜头的默认常量。

几何、稳定态和动作账本先于 TSX。六类运动来源分别为摄影机、对象、素材内部、效果参数、路径/遮罩、环境微动；连续动作按因果建模，不为拟合少数帧而无依据地分段停顿。

## 验证与批准

真实 MP4 的技术解码、正常速度观看与同帧证据缺一不可。保真批准由用户给出并绑定当前文件 SHA-256；文件变化后重新核对。Gate 1 不授予素材发布许可，也不等于可调用模板。

源素材、原文、Logo、水印、品牌和音乐仅在相应授权范围内用于分析。对外成片必须使用合法素材并经过独立核权与审查。本公开发行不附带彩色认证、生产调用或外部发布工具。

## 完成报告

报告镜头编号、当前模式、可播放文件、SHA-256、技术验证、用户视觉状态、已知差异、实际变更范围和耗时。首次复刻、用户等待与网络重连分开统计；技术测试不能代替人眼批准。
